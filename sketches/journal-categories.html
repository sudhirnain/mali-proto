Pregnancy uses a different hero — the weekly journey, not Milestones (which is parenting-only). Same three-tab IA; group taxonomy adapts to phase. "Notes to baby" is a new memory type that doesn't exist in the current build.

What the sketch is testing

  • Three navigation axes, symmetric — Timeline / Categories / Calendar. No content type dressed as a view-mode.
  • Group taxonomy — 5 groups per phase, ordered to privilege family record over tracker. Parenting: Memories · Development · Care logs · Health · Growth. Pregnancy: Memories · Your journey · Body & symptoms · Health · Growth.
  • Milestones hero — preserves the brand moat (progress bar, "Next: Holds head up") without occupying tab real estate.
  • Permanent discovery — empty tiles read "Not yet" instead of being suppressed. The "browse what you can track" cold-state strip is no longer cold-state-only.
  • Phase-aware — both phases share the IA, swap the hero, and re-bucket the content categories. Notes to baby + Bump photos + Letters surface as first-class pregnancy memory types.

Icons in this sketch are unicode placeholders — production would use the existing Illustration component and mali-art raster set. The Milestones hero would carry the milestone-art baby line drawing the build already has.
